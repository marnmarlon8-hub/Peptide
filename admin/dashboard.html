⚡ Supabase Database RLS Setup

If adding products or categories shows a Row-Level Security (RLS) error (code 42501), run this SQL script in your Supabase Dashboard → SQL Editor to grant insert and update permissions to authenticated admins:

-- Grant INSERT/UPDATE/DELETE RLS permissions to authenticated admins:

CREATE POLICY "Enable insert for categories" ON categories FOR INSERT TO authenticated WITH CHECK (true);
CREATE POLICY "Enable update for categories" ON categories FOR UPDATE TO authenticated USING (true);
CREATE POLICY "Enable delete for categories" ON categories FOR DELETE TO authenticated USING (true);

CREATE POLICY "Enable insert for products" ON products FOR INSERT TO authenticated WITH CHECK (true);
CREATE POLICY "Enable update for products" ON products FOR UPDATE TO authenticated USING (true);
CREATE POLICY "Enable delete for products" ON products FOR DELETE TO authenticated USING (true);

CREATE POLICY "Enable insert for product_variations" ON product_variations FOR INSERT TO authenticated WITH CHECK (true);
CREATE POLICY "Enable update for product_variations" ON product_variations FOR UPDATE TO authenticated USING (true);
CREATE POLICY "Enable delete for product_variations" ON product_variations FOR DELETE TO authenticated USING (true);

CREATE POLICY "Enable insert for reviews" ON reviews FOR INSERT TO authenticated WITH CHECK (true);
CREATE POLICY "Enable update for reviews" ON reviews FOR UPDATE TO authenticated USING (true);
CREATE POLICY "Enable delete for reviews" ON reviews FOR DELETE TO authenticated USING (true);

Note: Even before running this script, the admin panel automatically persists added products & categories locally so your website stays fully operational!
